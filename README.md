# ✈️ Stopover API

A serverless REST API for planning flight trips with stopovers, built on AWS Lambda, API Gateway and DynamoDB.

Built as part of the course **Cloud Development**

## Tech stack

| Layer | Technology |
| --- | --- |
| Runtime | Node.js 24 (ES modules), AWS Lambda on arm64 |
| API | Amazon API Gateway (HTTP API v2) |
| Database | Amazon DynamoDB (AWS SDK v3, `lib-dynamodb`) |
| Middleware | [Middy](https://middy.js.org/): JSON body parsing and HTTP error handling |
| Infrastructure | Serverless Framework v4 |
| Region | `eu-north-1` (Stockholm) |

## Architecture

```
Client ──► API Gateway (HTTP API) ──► Lambda handler ──► Service layer ──► DynamoDB
                                        │                   │
                                        │ HTTP concerns:    │ Data concerns:
                                        │ validation,       │ DynamoDB commands,
                                        │ status codes      │ DB error handling
```

- **Handlers** (`functions/*/index.mjs`) are thin. Each one reads the request, validates input, picks the status code and returns the response.
- **The service layer** (`services/flights.mjs`) holds every DynamoDB call. Handlers never touch the database directly, so the storage could be swapped without changing them.
- **`services/db.mjs`** creates one shared `DynamoDBDocumentClient`, which converts plain JavaScript objects to DynamoDB types.

## Endpoints

| Method | Path | Description | Success | Errors |
| --- | --- | --- | --- | --- |
| `GET` | `/api/flights` | List all flights, sorted by date | `200` | `400` |
| `GET` | `/api/flights/{id}` | Get one flight | `200` | `404` |
| `POST` | `/api/flights` | Create a flight | `201` | `400`, `422` |
| `PUT` | `/api/flights/{id}` | Replace a flight | `200` | `400`, `404` |
| `DELETE` | `/api/flights/{id}` | Delete a flight | `200` | `404` |

### Query parameters for `GET /api/flights`

All of them are optional and can be combined.

| Param | Example | Description |
| --- | --- | --- |
| `from` | `got` | Departure airport (case-insensitive) |
| `to` | `bkk` | Arrival airport (case-insensitive) |
| `maxPrice` | `5000` | Maximum price. Must be a number, otherwise `400` |

### Flight object

```json
{
  "id": "f6f955",
  "from": "GOT",
  "to": "DXB",
  "date": "2026-12-01",
  "airline": "Emirates",
  "price": 3200
}
```

`id` is generated by the API. `from` and `to` are stored in upper case.

### Request body for `POST` and `PUT`

```json
{
  "from": "got",
  "to": "dxb",
  "date": "2026-12-01",
  "airline": "Emirates",
  "price": 3200
}
```

`from`, `to`, `date` and `airline` must be strings and `price` must be a number. Otherwise the API returns `400`. Malformed JSON returns `422`.

## Example requests

```bash
# List flights from Gothenburg under 5000
curl "https://<your-api-id>.execute-api.eu-north-1.amazonaws.com/api/flights?from=got&maxPrice=5000"

# Create a flight
curl -X POST "https://<your-api-id>.execute-api.eu-north-1.amazonaws.com/api/flights" \
  -H "Content-Type: application/json" \
  -d '{"from":"got","to":"dxb","date":"2026-12-01","airline":"Emirates","price":3200}'

# Delete a flight
curl -X DELETE "https://<your-api-id>.execute-api.eu-north-1.amazonaws.com/api/flights/f6f955"
```

## Getting started

### Prerequisites

- Node.js 24+
- [Serverless Framework v4](https://www.serverless.com/framework/docs/getting-started)
- An AWS account with credentials configured

### 1. Install dependencies

```bash
npm install
```

### 2. Create the DynamoDB table

Create a table named **`flights-db`** in `eu-north-1` with:

- Partition key: `id` (String)
- Capacity mode: On-demand

### 3. Configure the IAM role

The Lambda role ARN is kept out of version control. Create a `config.yml` file in the project root (it is listed in `.gitignore`):

```yaml
role: arn:aws:iam::<account-id>:role/<your-lambda-role>
```

The role needs permission to read and write the `flights-db` table.

### 4. Deploy

```bash
serverless deploy
```

When you change only function code, you can redeploy a single function:

```bash
serverless deploy function -f getFlights
```
